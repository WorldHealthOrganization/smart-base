# Downloads

## FHIR Package Downloads

Large FHIR package files are published as [GitHub Release assets](https://github.com/WorldHealthOrganization/smart-base/releases) rather than being served from this site. Each release is tagged with the IG version.

Available assets per release:

| File | Description |
|------|-------------|
| `package.tgz` | FHIR NPM package (R4) |
| `package.r4.tgz` | FHIR NPM package (R4 specific) |
| `package.r4b.tgz` | FHIR NPM package (R4B specific) |
| `package.db` | FHIR package database (SQLite) |
| `ai.zip` | AI-ready package archive |

[Browse all releases](https://github.com/WorldHealthOrganization/smart-base/releases)
