Logical Model: Knowledge graph L2: Business Process Workflow

Official URL: http://smart.who.int/base/StructureDefinition/KGBusinessProcess Version: 0.3.0
Active as of 2026-11-23 Computable Name: KGBusinessProcess

DAK component 4. NOT the BPMN file – the component that points at one. source 1..1 uri is that pointer, and the BPMN's interior is the l2-bpmn subgraph, reached through the external-artifact this sourcedFrom targets. objectives 1..1 markdown is required by BusinessProcessWorkflow.fsh and has no counterpart anywhere in BPMN XML, so it can only ever come from the FSH instance. resolutionStatus is unresolved on a component that something else names but no DAK declares – an L3 artefact whose title carries the component id, for instance. The node exists so the gap is queryable and carries the referenced id and nothing else. Class IRI: http://smart.who.int/kg/business-process.
